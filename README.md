## The haiku (64 characters)

> Three a.m. cursor
> blinks at the breakpoint I set
> the bug: a typo

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` as a fallback). The program guards the gate itself: exactly three lines, 1–200 characters, not whitespace-only.

## Why this haiku

The picture at the centre is concrete — a cursor blinking at a breakpoint at three in the morning, the exact scene every debugger knows. The turn lands in the last line: after a whole night staring at the breakpoint, the bug was only ever a typo. Every word earns its place; nothing is filler added to reach the syllable count.
